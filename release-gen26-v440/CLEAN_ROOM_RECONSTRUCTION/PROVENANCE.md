# CLEAN_ROOM_RECONSTRUCTION

This directory intentionally identifies reconstructed code rather than claiming byte-for-byte historical identity.

The active runtime used for STAGE1 did not contain the original historical `tdc_gen26_integrated_v440.py`. The current implementation was reconstructed from the project's integrated v440 mechanism inventory and historical state descriptions. It is API-compatible with this package and is the basis of `CURRENT_CANONICAL_IMPLEMENTATION`.
