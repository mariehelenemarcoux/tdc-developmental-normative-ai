# TDC and Machine-Consciousness Research

TDC is explicitly intended to be usable as a **functional research framework** for machine-consciousness hypotheses.

It does not claim that TDC is conscious.

## Researchable functional properties

TDC can operationalize questions such as:

- Does a system maintain persistent self-relevant state across time?
- Can it distinguish external reward from internally represented normative authority?
- Can it detect conflicts among internal tendencies?
- Can it evaluate and revise its own learned representations?
- Can it reorganize developmental state while preserving invariants?
- Does memory produce continuity rather than only retrieval?
- Can metacognitive checks alter action selection?
- Do developmental changes improve the reliability of internal evaluative representations?

## What would count as evidence?

Current experiments provide evidence only for **functional computational behavior in synthetic environments**.

Evidence about phenomenal consciousness would require additional theory, operational definitions, competing hypotheses, and tests not reducible to behavioral success in the current benchmark family.

## Recommended framing

> TDC can be used to experimentally explore functional properties sometimes discussed in machine-consciousness research, including metacognition, persistent internal state, self-directed developmental regulation, internal conflict resolution, and memory-mediated continuity. The architecture does not assume that these properties imply subjective experience.
